# Chess.com Confirm Move Hotkeys

[English version](README.md)

Мінімальне Chrome/Chromium-розширення Manifest V3 для керування вікном
підтвердження ходу на Chess.com за допомогою клавіатури.

## Локальне встановлення

Розширення не розповсюджується через Chrome Web Store. Його потрібно
встановити як unpacked extension із локальної копії цього репозиторію.

### 1. Отримайте файли розширення

Виберіть один із варіантів:

- Клонуйте репозиторій:

  ```bash
  git clone https://github.com/saladin-uzh/chess-confirm-move-hotkeys.git
  ```

- Або виберіть **Code → Download ZIP** на GitHub і розпакуйте завантажений
  архів. Не намагайтеся завантажити ZIP-файл безпосередньо в Chrome.

### 2. Завантажте unpacked extension

1. Відкрийте `chrome://extensions` у Chrome або Chromium-браузері.
2. Увімкніть **Developer mode**.
3. Натисніть **Load unpacked**.
4. Виберіть розпаковану папку `chess-confirm-move-hotkeys`, яка містить
   `manifest.json`.
5. Перезавантажте вкладки Chess.com, які вже були відкриті.

Після отримання оновлень через Git або повторного завантаження натисніть
**Reload** на картці розширення в `chrome://extensions`, а потім перезавантажте
вкладку Chess.com.

## Гарячі клавіші

- `Space` — підтвердити хід.
- `Escape` — скасувати хід.

Розширення обробляє клавішу лише тоді, коли відповідна видима й активна кнопка
підтвердження або скасування присутня на сторінці. Воно ігнорує події у формах,
текстових полях і редагованих елементах, а також комбінації з
клавішами-модифікаторами.

## Підтримувані сторінки

Content script запускається лише на таких URL:

- `https://www.chess.com/play/*`
- `https://www.chess.com/game/*`
- `https://www.chess.com/analysis/game/*`

## Усунення проблем

- Перезавантажте вкладку Chess.com після встановлення або оновлення розширення.
- Переконайтеся, що підтвердження ходу ввімкнене в налаштуваннях Chess.com.
- Відкрийте консоль сторінки та знайдіть повідомлення
  `[Chess.com Confirm Move Hotkeys] Initialized.`
- Перевірте, що поточний URL відповідає одному з підтримуваних шаблонів.

## Безпека та приватність

Розширення не запитує додаткових дозволів, не виконує зовнішніх мережевих
запитів і не збирає та не передає дані. Воно запускається лише на перелічених
URL Chess.com.
